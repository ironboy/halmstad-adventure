Adventure Engine Class Diagram

The helper classes students are given, and the classes they write themselves. Concrete rooms and characters are shown as generic placeholders. Updated 24/9 with IInteractive, Direction, ToString() and the dev teleport.

  • Helper classes (given, not meant to be read)
  • Student-written classes

Reading the diagram

  • Visibility: + public, # protected, ~ internal, - private. A trailing $ marks a static member.
  • Hollow arrow is inheritance. Dashed hollow arrow is "implements interface". Dashed arrow is a dependency (one class calls the other). Filled diamond is ownership (LocationX creates and holds its NpcA). Hollow diamond is aggregation (World holds the Locations it was handed).
  • Interface vs abstract class: IInteractive lists what every interactive thing must have. Interactive is the abstract class that actually implements it and adds the code. A class can inherit one base class but implement any number of interfaces.
  • Enum: Direction has exactly four values. Location loops over them to add exits; direction.ToString() gives "North", which is also the name of the method North() the menu calls.
  • Blocking an exit: the direction methods on Location are virtual, so LocationX overrides East() and only calls base.East() when its Npc's flag is set. The menu still shows "Go east" because exits come from the grid, not from the room.
  • Placeholders: LocationX, LocationY, LocationZ and NpcA stand for any concrete room or character. The shipped example maps them to RuneRoom, Courtyard, Gate and Guard.

    direction TB

    class IInteractive {
        <<interface>>
        +Name : string
        +Description : string[]
        +Actions : string[]
        +Run()
    }

    class Interactive {
        <<abstract>>
        +Name : string
        +Description : string[]
        +Actions : string[]
        #ExitLabel : string
        ~AllActions() List~string~
        +Run()
        +ToString() string
    }

    class Direction {
        <<enumeration>>
        North
        East
        South
        West
    }

    class Menu {
        +Title : string
        -_children : List~Menu~
        +Create(lines, instance)$ Menu
        +Close()$
        +Run(exitLabel)
        ~RunOnce(exitLabel) bool
    }

    class World {
        -_map : Location[][]
        -_x : int
        -_y : int
        -_byClassName : Dictionary~string, Location~
        +DevMode : bool
        +At(x, y) Location
        +LocationNames : IEnumerable~string~
        +Find(className) Location
        +Teleport(className) bool
        +Play()
        ~MoveTo(x, y)
    }

    class Location {
        <<abstract>>
        ~World : World
        ~X : int
        ~Y : int
        ~AllActions() List~string~
        +North()
        +East()
        +South()
        +West()
        +ShowInventory()
        +DevTeleport()
        -Neighbour(direction) Location
        -Move(direction)
        -Delta(direction)$
    }

    class Npc {
        <<abstract>>
        #ExitLabel = "Stop talking"
    }

    class Player {
        <<static>>
        +Inventory$ : List~string~
        +Has(item)$ bool
    }

    class Game {
        +Actions : string[]
        +Start()
        +Help()
    }

    class LocationX {
        -_npc : NpcA
        -_someFlag : bool
        +Description : string[]
        +Actions : string[]
        +SomeAction()
        +TalkToNpc()
        +East()
    }

    class LocationY {
        -_someFlag : bool
        +Actions : string[]
        +TakeItem()
    }

    class LocationZ {
        -_someFlag : bool
        +Actions : string[]
        +UseItem()
    }

    class NpcA {
        +SomeFlag : bool
        +Description : string[]
        +Actions : string[]
        +SomeReply()
    }

    IInteractive <|.. Interactive : implements
    Interactive <|-- Game
    Interactive <|-- Location
    Interactive <|-- Npc
    Location <|-- LocationX
    Location <|-- LocationY
    Location <|-- LocationZ
    Npc <|-- NpcA

    Interactive ..> Menu : Run() builds menu from Actions
    Menu ..> Interactive : calls methods by name
    Game ..> World : Start() creates map, sets DevMode
    World "1" o-- "*" Location : _map grid + _byClassName
    Location --> World : back-reference
    Location ..> Direction : exits generated per value
    Location ..> Menu : Close() after move
    Location ..> Player : ShowInventory
    LocationX *-- NpcA : owns, calls Run()
    LocationY ..> Player : Inventory.Add
    LocationZ ..> Player : Has(item)
